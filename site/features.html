Control surfaces

Hardware, browser, phone — pick any.

  • Elgato Stream DeckPlug it in and the daemon picks it up, with per-device page assignment and live key images.
  • Browser panelThe full deck in any browser on your LAN — same state, live updates over WebSocket.
  • Phone as a remotePair over LAN with a QR code, or from anywhere through the private relay — P2P first, relay fallback. Sealed end to end; see Security.
  • Per-device displayBrightness, auto-dim after idle seconds, and idle actions (off, dim, clock) — per device, applied live.
Automation

Buttons that think a little.

  • VariablesGlobal {{vars.x}} store shared by actions, the API and flows — set them from any button.
  • Event flowsTrigger on variable changes, timers, calendar, media and integration events, or client connect.
  • Macros & conditionalsMultiaction sequences plus flow-control branching, all runnable from one press.
  • Webhooks both waysFire HTTP requests out, or let the outside world trigger your deck in.
  • MCP serverLet AI assistants drive your deck: scoped tokens (ldmcp_…, shown once, hashed at rest) over Streamable HTTP.
Ownership

Run it your way. Keep it safe.

  • Local-first coreBun + SQLite daemon idling around 100 MB. No cloud account, no resident Chromium.
  • Profiles & pagesNamed decks per context, unique page names per profile, drag to reorder.
  • Versioned backupsExport everything (or single sections), validate before restore, watch progress live — per-profile export too.
  • Managed updatesThe Rust launcher updates daemon + panel with backup and rollback; sdctl CLI scripts the rest.
  • Autostart everywhereOne setting; the launcher wires Windows Run, Linux autostart and macOS LaunchAgents.
  • Open & legibleMIT licensed, English + Spanish UI, and a live log stream for everything the deck does.
